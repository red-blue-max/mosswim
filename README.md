# MOSSWIM — сайт школы плавания

Статический многостраничный сайт: чистые HTML/CSS/JS, без CMS и сборщиков.
Разворачивается на GitHub Pages, заявки уходят через Web3Forms на почту и в Telegram.

---

## Структура

```
index.html          Главная
about.html          О школе
programs.html       Программы обучения (7 программ, якоря #deti, #vzroslye, ...)
camps.html          Выездные сборы
coaches.html        Тренеры (сетка)
coach-1..6.html     Индивидуальные страницы тренеров
pools.html          Бассейны и локации
schedule.html       Расписание + запись по клику на занятие
prices.html         Цены и абонементы
reviews.html        Отзывы
contacts.html       Контакты
privacy.html        Политика обработки персональных данных (ШАБЛОН)
404.html            Страница ошибки

css/style.css       Вёрстка и дизайн-система
css/anim.css        Всё, что двигается: вода, пузырьки, блики, аккордеоны
js/main.js          Меню, анимации, счётчики, аккордеоны, модалка, формы
assets/img/lane.svg Разделительная дорожка бассейна (тёмный вариант — lane-dark.svg)
assets/img/         Логотип, иконки, og-картинка, сюда же — фото
assets/video/       Сюда положить hero.mp4 для главного экрана
CNAME               Домен для GitHub Pages
sitemap.xml         Карта сайта
robots.txt          Индексация
```

Шапка и подвал физически продублированы в каждом файле — это норма для статического
сайта без сборщика. Меняете меню или телефон — правьте во всех файлах разом (см. ниже).

**Разделители-дорожки** рисуются автоматически на верхней кромке каждой секции
(`.section::before` в `css/style.css`), в разметке для этого ничего не нужно.
Чтобы убрать дорожку у конкретной секции, добавьте ей класс `section--flat`.
Цвета дисков лежат в `assets/img/lane.svg` — это обычный SVG, правится текстом.

**Длинные объяснения** спрятаны в аккордеоны. Разметка одного пункта:

```html
<div class="acc__item">
  <button class="acc__btn" aria-expanded="false">Вопрос<span class="acc__sign"></span></button>
  <div class="acc__panel"><div class="acc__inner"><p>Ответ.</p></div></div>
</div>
```

## Локальный просмотр

Из папки проекта:

```bash
python -m http.server 8765
```

Затем откройте http://localhost:8765 — просто двойным кликом по `index.html` открывать
не стоит, часть путей и шрифты ведут себя иначе.

## Что обязательно сделать перед публикацией

### 1. Подключить приём заявок (Web3Forms)

1. Зарегистрируйтесь на https://web3forms.com и создайте Access Key на нужный e-mail.
2. В личном кабинете Web3Forms подключите Telegram-уведомления.
3. Откройте `js/main.js`, строка 15, и замените:

```js
accessKey: 'YOUR-WEB3FORMS-ACCESS-KEY',
```

на свой ключ. До этого момента все формы показывают предупреждение и ничего не отправляют.

Формы на сайте: главная (пробное занятие), модальное окно записи (работает на всех
страницах), сборы (предзапись), отзывы, контакты. Все используют один ключ.

### 2. Заменить контакты во всех файлах

Телефон, почта и соцсети стоят заглушками. Из папки проекта (Git Bash / WSL):

```bash
grep -rl "+70000000000" --include="*.html" . | xargs sed -i "s/+70000000000/+74951234567/g"
```

Аналогично поменяйте:

| Заглушка | Что это |
|---|---|
| `+70000000000` | телефон в ссылках `tel:` и `wa.me` |
| `+7 (000) 000-00-00` | телефон как текст |
| `info@mosswim.ru` | почта |
| `https://t.me/mosswim` | Telegram |
| `https://vk.com/mosswim` | ВКонтакте |

### 3. Заполнить контент

Полный список — в `CONTENT.md`. Ключевое: тренеры, адреса бассейнов, цены,
даты сборов, расписание, фотографии.

### 4. Проверить политику конфиденциальности

`privacy.html` — это заготовка, а не готовый документ. Реквизиты оператора не заполнены,
формулировки нужно согласовать с юристом. Отдельно обратите внимание: Web3Forms —
зарубежный сервис, это трансграничная передача персональных данных, её нужно корректно
отразить в документах и уведомлении в Роскомнадзор.

## Фотографии и видео

Файлы кладутся в `assets/img/` с точными именами — вёрстка подхватит их сама,
а пока файла нет, на его месте аккуратная синяя заглушка (сайт не ломается).

| Имя файла | Где появится |
|---|---|
| `hero-swimmer.jpg` / `.webp` | фото пловца в правой части главного экрана (уже стоит) |
| `hero-swimmer-sm.jpg` / `.webp` | облегчённая версия того же фото для телефонов |
| `hero.jpg` | постер главного экрана под видео |
| `assets/video/hero.mp4` | фоновое видео главного экрана |
| `coach-1.jpg` … `coach-6.jpg` | карточки тренеров (вертикальные, 4:5) |
| `pool-altayskaya.jpg` | бассейн на Алтайской |
| `pool-vdnh.jpg` | бассейн у ВДНХ |
| `pool-pirogovskiy.jpg` | бассейн в Пироговском |
| `pool-pyalovo.jpg` | бассейн в Пялово |
| `prog-deti.jpg`, `prog-vzroslye.jpg`, `prog-tehnika.jpg`, `prog-sport.jpg`, `prog-beremennye.jpg`, `prog-ovz.jpg`, `prog-triatlon.jpg` | иллюстрации программ |

Рекомендации: ширина 1600–1920 px, JPEG качества 80–85, вес до 300 КБ на снимок.
Видео для героя — 8–15 секунд, без звука, до 4–5 МБ.

**Про фото в главном экране.** Оно лежит в блоке `.hero__photo` и растворяется в фоне
радиальной маской (`css/style.css`, секция «Фотография пловца справа»). Чтобы заменить
снимок, положите свой файл под теми же именами — маска и тонировка подхватятся сами;
кадрирование настраивается свойством `object-position`. Если позже добавите фоновое
видео `hero.mp4`, фото лучше убрать или приглушить: два слоя будут спорить между собой.

Иконки и логотип уже подготовлены из `logo.jpg`:
`assets/img/logo.png` (прозрачный фон, для шапки), `icon-32/48/180/192/512.png`, `og-cover.jpg`.

## Карты

На страницах «Бассейны» и «Контакты» есть блоки-заглушки под карту. Соберите карту
с метками на https://yandex.ru/map-constructor и вставьте полученный `<iframe>`
внутрь этих блоков вместо заглушки (в коде помечено комментарием).

## Публикация: автоматическая выгрузка на Timeweb

Сайт живёт на хостинге Timeweb. Выгрузка настроена через GitHub Actions:
после `git push` в ветку `main` файлы уезжают на сервер сами.

### Разовая настройка

В репозитории: **Settings → Secrets and variables → Actions → New repository secret**.
Нужны четыре значения:

| Имя секрета | Что положить | Где взять |
|---|---|---|
| `FTP_SERVER` | адрес FTP-сервера | панель Timeweb, блок «Доступ по FTP» |
| `FTP_USERNAME` | логин FTP | там же |
| `FTP_PASSWORD` | пароль FTP | там же |
| `FTP_DIR` | каталог сайта со слэшем на конце, например `/mosswim.ru/public_html/` | файловый менеджер |

Секреты хранятся зашифрованными, в логах сборки они маскируются.

**Безопаснее завести отдельного FTP-пользователя** (в панели: «Аккаунт» →
«Пользователи ПУ/FTP») с доступом только к каталогу сайта, а не использовать
логин от самой панели. Тогда даже при утечке секрета под угрозой будет
только эта папка.

### Как это работает

1. Сборка кладёт в папку `dist` только то, что нужно серверу: страницы,
   `css`, `js`, `assets`, `.htaccess`, `robots.txt`, `sitemap.xml`.
   `README.md`, `CONTENT.md`, исходники фотографий и служебные файлы git
   на хостинг не попадают.
2. Выгружаются только изменившиеся файлы — обновление идёт за секунды.
3. Файлы, удалённые из репозитория, удаляются и на сервере.
   Старые страницы не остаются висеть.
4. Правки только в `.md` сборку не запускают.

### Первый запуск и полная очистка

Если на сервере остались файлы от ручных загрузок, запустите выгрузку
с полной очисткой: вкладка **Actions** → «Выгрузка сайта на Timeweb» →
**Run workflow** → включить галочку «Полностью очистить папку на сервере».

Так же стоит поступить, если сайт начал вести себя странно после правок:
очистка гарантирует, что на сервере лежит ровно то же, что в репозитории.

### Обновление сайта

```bash
git add -A && git commit -m "описание правки" && git push
```

Через минуту-две изменения на `mosswim.ru`. Статус видно во вкладке
**Actions**; при ошибке приходит письмо.

## После запуска

- Подключите Яндекс.Метрику и Яндекс.Вебмастер, добавьте `sitemap.xml`.
- Проверьте скорость через PageSpeed Insights — тяжёлые фото главный риск.
- Проверьте формы: отправьте тестовую заявку и убедитесь, что письмо и сообщение
  в Telegram дошли.
